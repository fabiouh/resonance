# Security

## Supported versions

There are no published application releases yet. Security fixes currently target `main`. Once releases are available, only the latest release will receive security updates.

## Reporting a vulnerability

Do not initially disclose vulnerabilities or credentials in public issues.

Use GitHub's **Report a vulnerability** option in this repository's Security tab if it is available. If private reporting is unavailable, open an issue requesting a private reporting channel without including vulnerability details.

In a private report, include the affected version, impact, and reproduction steps. Remove tokens, personal account information, and other secrets from logs and screenshots.
